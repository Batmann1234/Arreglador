# ArreglarItems

`/arreglar` abre un menú. Con el menú abierto, shift + click derecho a un ítem de MythicMobs de tu inventario:
- Sin runas: se destruye y recibes su versión nueva (`mm i give`).
- Con runas: se cierra el menú y se abre `/rompedor` para sacarlas primero.

Solo funciona con los IDs de `items:` en `config.yml`.

Requisitos: Paper/Purpur 1.21.x, Java 21, MythicMobs, AdvancedEnchantments y RompedorEncantamientos.
Compilar: sube el repo a GitHub y descarga el artefacto `ArreglarItems` en Actions.
